# Practical 09: Item Management Using STL Vector

## Problem statement

Design a C++ program that uses the STL vector container to store, sort, and search a collection of Item records. The Item class will have attributes such as: Item Code, Item Name, Cost, Quantity. You will: Allow the user to input several item records, Sort the records based on different criteria such as item code, cost, and quantity, perform a search for an item by its item code or name, Display the sorted list of items and search results.

## Concepts demonstrated

STL vector, algorithms, item records, insertion, display, search, sort and delete.

## Source file

- `stl_vector.cpp`

## Compile and run

From this folder:

```bash
g++ -std=c++17 -Wall -Wextra stl_vector.cpp -o practical
./practical
```

On Windows with MinGW:

```powershell
g++ -std=c++17 -Wall -Wextra stl_vector.cpp -o practical.exe
.\practical.exe
```

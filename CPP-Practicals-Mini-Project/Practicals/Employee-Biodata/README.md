# Practical 03: Employee Bio-Data Using Multiple Inheritance

## Problem statement

Create employee bio-data using following classes i) Personal record ii)) Professional record iii) Academic record Assume appropriate data members and member function to accept required data & print bio-data. Create bio-data using multiple inheritance using C++. Use a virtual base class to avoid ambiguity.

## Concepts demonstrated

Multiple inheritance, virtual base classes, data members and member functions.

## Source file

- `employee_biodata.cpp`

## Compile and run

From this folder:

```bash
g++ -std=c++17 -Wall -Wextra employee_biodata.cpp -o practical
./practical
```

On Windows with MinGW:

```powershell
g++ -std=c++17 -Wall -Wextra employee_biodata.cpp -o practical.exe
.\practical.exe
```
